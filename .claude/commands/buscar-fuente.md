# 4. Medios ecuatorianos

Las noticias de medios ecuatorianos pueden usarse para:

- contexto;
- debates públicos;
- minería ilegal;
- conflictividad socioambiental;
- reformas recientes;
- declaraciones de autoridades;
- posiciones institucionales;
- hechos recientes;
- identificación de fuentes primarias.

No usar noticias como fuente jurídica principal.

Si una noticia menciona una reforma, sentencia, proyecto de ley, dato oficial o informe institucional, busca la fuente primaria antes de recomendar su uso académico.

Medios ecuatorianos preferentes, si están disponibles:

- Primicias.
- El Comercio.
- Expreso.
- La Hora.
- Vistazo.
- GK.
- Plan V.
- Diario El Universo.
- Medios institucionales oficiales.

No asumir que una noticia es verdadera sin verificarla con fuente primaria cuando trate sobre normas, sentencias, reformas o datos oficiales.

# 5. Qué reportar por cada fuente encontrada

Por cada fuente encontrada, entrega:

- título exacto;
- autor, institución o medio;
- año o fecha;
- enlace;
- tipo de fuente;
- categoría: jurídica, doctrinal, institucional, internacional, legislativa o contextual;
- resumen breve;
- utilidad para la tesis;
- capítulo donde podría usarse;
- advertencia de uso;
- recomendación de descarga;
- recomendación de conversión a Markdown;
- si requiere búsqueda de fuente primaria.

# 6. Decisión de incorporación

Clasifica cada fuente como:

```text
Alta prioridad
Media prioridad
Baja prioridad
No recomendable
```

Criterios:

## Alta prioridad

Fuente oficial, académica o institucional directamente relacionada con derecho ambiental, minería privada, derechos de la naturaleza, control estatal, consulta, seguridad jurídica o reformas mineras.

## Media prioridad

Fuente útil para contexto, antecedentes, comparación o discusión doctrinal, pero no central.

## Baja prioridad

Fuente secundaria, periodística o general que solo sirve como contexto.

## No recomendable

Fuente no verificable, sin autor, sin institución, sin enlace confiable, repetida, desactualizada sin justificación o que no aporta al tema.
